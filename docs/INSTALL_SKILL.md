# Install this skill archive

This ZIP contains one `palworld-guide` folder. Keep that folder intact and copy it into your chosen project's `.agents/skills/` directory. Open that project in Codex and invoke `$palworld-guide`. Python 3.11+ and terminal/file access are required. Research fallback also requires the assistant's real search/page-reading tools; the CLI alone does not provide search.

The separate source archive includes an explicit project installer, tests, CI configuration, release tools and the full README. This skill archive includes the runtime, references, license and third-party notices. Preserve an existing installation before replacing it; the source installer refuses overwrites.

Breeding works offline. Other tools need public network access or a dated populated cache. The public candidate intentionally omits saved community recipe/demo snapshots, bulk place labels and terrain images. Runtime source attributions and data-version limits remain visible. Read `references/workflow.md` and `references/research.md` for task execution and automatic host handoff/resume.

This is a local Beta candidate, not evidence of independent-user validation. No MCP service, account connection or live server administration is included.
